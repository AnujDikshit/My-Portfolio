## About

A clean, modern, single-page portfolio built to showcase experience, projects, skills, and certifications for internship and entry-level Data Analyst opportunities.

- **Hero** — introduction with an interactive mini data-dashboard visual
- **About** — background and analytical approach
- **Experience** — IBM (Data Analyst Intern) and Hexa View Pvt. Ltd. (Virtual Model Trainer)
- **Skills** — Python, SQL, Pandas, NumPy, Matplotlib, Scikit-learn, Power BI, Tableau, Excel, PostgreSQL, Git
- **Projects** — Customer Shopping Behavior Analysis, Iris Classification
- **Certifications** — Harvard CS50, IBM Cognos Analytics, Microsoft Power BI (PL-300), CampusX
- **Education** — Babu Banarasi Das University (CGPA 9.0)
- **Contact** — direct email, LinkedIn, GitHub, and a contact form

## Tech Stack

- HTML5, CSS3 (custom properties, responsive grid/flexbox)
- Vanilla JavaScript (no frameworks)
- Deployed on [Vercel](https://vercel.com)

## Run Locally

This is a single self-contained `index.html` file — no build step required.

```bash
git clone https://github.com/AnujDikshit/portfolio.git
cd portfolio
open index.html   # or just double-click the file
```
